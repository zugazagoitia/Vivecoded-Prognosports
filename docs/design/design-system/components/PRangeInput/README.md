# PRangeInput

Slider with a value chip and optional tick labels.

Source: `src/components/lib/forms/PRangeInput.vue` (Vue 3 SFC, hand-rendered here as static Tailwind markup).

## What the consumer provides
`v-model` (number), `min` and `max` (all required); `step` (default 1); `ticks` to print every step under the track.
