## Objetivo
Crear el esqueleto del nuevo frontend en este repositorio: Vue 3.5 + Vite + TypeScript estricto + pnpm. Todas las demás issues parten de aquí, así que debe quedar listo para que se pueda trabajar en paralelo en T2–T15, F* y N* sin tocar la configuración base.

## Alcance
- Proyecto Vite + Vue 3.5 con Composition API y `<script setup lang="ts">` en todos los componentes. Sin Options API.
- TypeScript con `strict: true`, `noUncheckedIndexedAccess: true` y `vue-tsc --noEmit` como script `typecheck`.
- pnpm con versión fijada en `package.json` (`packageManager` y `devEngines`). Lockfile versionado.
- Node fijado en `.nvmrc` / `engines` (LTS vigente al hacer el scaffold).
- Modos de Vite `development`, `beta` y `production` (`.env`, `.env.beta`, `.env.production`). Banner «Estás utilizando PrognoSports Beta» visible solo en modo `beta` (texto y estilo del tablero Estados: alerta `info` con icono).
- Variables de entorno tipadas en `src/env.d.ts` y validadas al arrancar con Zod (`VITE_API_BASE_URL`, `VITE_GIT_SHA`, `VITE_GIT_DATE`, `VITE_APP_VERSION`). Si falta una obligatoria, la app no arranca y muestra un error claro en consola. Ninguna `VITE_*` contiene secretos (§23.4).
- `vite.config.ts` calcula `VITE_GIT_*` con `git` cuando no vienen del entorno (CI los pasa, ver T11) y los expone para el pie de página (N1: «v2.0.0 · build 4f2a9c1 · 10 oct 2026»).
- Alias `@/` → `src/`.
- Estructura de carpetas propuesta (documentada en el README):
  - `src/api/` (T2), `src/router/` y `src/pages/` (T3), `src/stores/` y `src/queries/` (T4), `src/i18n/` (T5), `src/flags/` (T6), `src/components/ui/` (F3), `src/components/data/` (F4), `src/components/charts/` (F5), `src/components/layout/` (N1–N4), `src/styles/` (F1–F2), `src/composables/`, `src/utils/`.
- `index.html` con `lang="es"`, `<meta name="viewport">`, `theme-color` claro/oscuro, `preconnect` a `VITE_API_BASE_URL` (§23.7) y favicon temporal.
- Instalación de dependencias base (versiones estables más recientes): `vue`, `vue-router`, `pinia`, `@tanstack/vue-query`, `zod`, `@vueuse/core`. El resto lo añade cada issue.
- README con: requisitos, `pnpm install`, `pnpm dev`, `pnpm build --mode beta`, scripts disponibles y estructura.
- Retirar cualquier rastro de Bulma/Oruga: no se instalan (§16.1).

## Criterios de aceptación
- [ ] `pnpm install --frozen-lockfile && pnpm dev` levanta la app con una página en blanco con el texto «PrognoSports».
- [ ] `pnpm build`, `pnpm build --mode beta` y `pnpm typecheck` terminan sin errores.
- [ ] En modo `beta` aparece el banner de beta; en `production` no.
- [ ] Arrancar sin `VITE_API_BASE_URL` falla con un mensaje que nombra la variable.
- [ ] `VITE_GIT_SHA` y la fecha de build están disponibles en `import.meta.env` y tipados.
- [ ] No hay `any` implícito ni errores de `vue-tsc`.
