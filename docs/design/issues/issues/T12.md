## Objetivo
Desplegar en Cloudflare Workers con Static Assets, en plan gratuito, desde GitHub Actions: previews por PR, beta automática y producción con aprobación manual, en paralelo a la web actual (URLs `workers.dev`, sin tocar DNS).

## Alcance
- **`wrangler.jsonc`** (§22.1): `assets.directory: "./dist"`, `assets.not_found_handling: "single-page-application"`. Sin código de Worker propio salvo que haga falta para cabeceras (§22.2, ver T13). Nada sensible en el archivo (§22.10).
- **Previews por PR** (§22.3): `wrangler versions upload` con el `dist/` del artefacto de T11 (construido con `VITE_PREVIEW=true` para el panel de flags de T6), y comentario en la PR con la URL. **Verificar** que la URL de preview de versión existe en el plan Free; si no, Worker por PR `prognosports-pr-<n>` y borrado al cerrar.
- **Beta** (§22.4): push a la rama de integración → `wrangler deploy` a `prognosports-beta` (entorno GitHub `beta`). Usa la API de producción.
- **Producción paralela** (§22.5): push a la rama de producción → `wrangler deploy` a `prognosports`, tras aprobación manual en el entorno `production` (§21.9).
- **Caché** (§22.7): ficheros con hash `public, max-age=31536000, immutable`; `index.html` `no-cache`.
- **Rollback** (§22.8): documentado en `docs/deploy.md` (`wrangler rollback` y desde el panel).
- **Limpieza** (§22.9): job al cerrar la PR que borra versiones/Workers de preview.
- **Secretos** (§22.10): `CLOUDFLARE_API_TOKEN` (solo «Workers Scripts: Edit» de la cuenta) y `CLOUDFLARE_ACCOUNT_ID` en los entornos de GitHub.
- Límites para no gastar (§22): no usar KV, D1, R2, Durable Objects, Queues ni Workers Paid; sin dominio propio.

## Criterios de aceptación
- [ ] Una PR del repo recibe un comentario con su URL de preview y la app funciona en rutas profundas (recarga en `/ranking/x/2026`).
- [ ] Fusionar en la rama de integración publica beta sin intervención.
- [ ] Producción no se publica sin aprobación.
- [ ] `index.html` se sirve con `no-cache` y los assets con `immutable`.
- [ ] Cerrar una PR elimina su preview.
- [ ] El procedimiento de rollback está escrito y probado una vez en beta.
