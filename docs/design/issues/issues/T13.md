**Referencia:** `docs/requisitos.md` §22.6, §23.3, §23.4, §24.8

## Objetivo
Endurecer el frontend: CSP estricta, cabeceras de seguridad y una política clara sobre el token de sesión mientras siga en `localStorage`.

## Alcance
- **Cabeceras** en todas las respuestas (vía `_headers` si Static Assets lo admite, o Worker mínimo con `run_worker_first` solo para HTML; ver T12):
  - `Content-Security-Policy`: `default-src 'self'`; `script-src 'self'` (sin `unsafe-inline` ni `unsafe-eval`); `style-src 'self'` (+ `'unsafe-inline'` solo si ECharts/MapLibre lo exigen, documentado); `img-src 'self' data: blob: <dominio de la API> <teselas OSM/CARTO>`; `connect-src 'self' <API> <Sentry> <Cloudflare Web Analytics> <teselas>`; `font-src 'self'`; `frame-ancestors 'none'`; `base-uri 'self'`; `form-action 'self'`; `object-src 'none'`.
  - `Strict-Transport-Security`, `X-Content-Type-Options: nosniff`, `Referrer-Policy: strict-origin-when-cross-origin`, `Permissions-Policy` restrictiva (cámara, micro, geolocalización desactivados).
- **Token** (§23.3): en `localStorage` mientras la API no ofrezca cookies httpOnly. Mitigaciones: CSP, prohibido `v-html` con datos de usuario (lint T8), saneado con DOMPurify de cualquier HTML que llegue de la API, logout que borra el token y revoca en `/auth/logout`.
- **Datos sensibles** (§24.8): ninguna vista renderiza `email` de otros usuarios ni `hashedPassword` (T2 ya lo elimina); test que lo comprueba.
- **Variables** (§23.4): comprobación en CI de que `dist/` no contiene nada con forma de secreto (`CLOUDFLARE_`, tokens).
- Enlaces externos con `rel="noopener noreferrer"`.
- Documento `docs/security.md` con la política y el informe de hallazgos para backend (p. ej. si la API devuelve `hashedPassword`).

## Dependencias

## Criterios de aceptación
- [ ] La beta obtiene A o superior en un analizador de cabeceras (p. ej. securityheaders.com).
- [ ] No hay violaciones de CSP en la consola recorriendo Inicio, Pronosticar, Ranking, Circuito (mapa) y Admin.
- [ ] Un intento de inyectar `<script>` en la bio de un usuario se muestra como texto.

## Tests
- E2E: escucha `securitypolicyviolation` y falla si se dispara.
- Unitario: el saneado elimina `<script>` y atributos `on*`.
