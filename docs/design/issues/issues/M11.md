## Objetivo
Consulta de todas las comunidades para el admin: acceso (abierta o cerrada), número de jugadores y reglas, con enlace para verla. Es solo lectura porque la API no permite editar ni eliminar comunidades desde administración.

## Ruta y acceso
- Ruta propuesta: `/admin/comunidades` (rutas tipadas y carga perezosa de T3, bajo el layout admin de N4).
- Requiere sesión: sí, con correo verificado (guards `auth` y `verified`, requisito 1.6).
- Rol: administrador (guard `admin`: `User.rank.admin === true`; si no, redirige a `/404`, requisito 12.1). No necesita comunidad activa.
- Entradas: enlace «Comunidades» del grupo «Personas» de `AdminSide`; fila «Comunidades» de M1m.
- Salidas: botón «Ver» de cada fila → H5 (Comunidad) de esa comunidad (⚠️ a confirmar si el admin puede abrir H5 sin ser miembro: guard `community`/`GET .../validate`).

## Dependencias
T2, T3, T4, T7, F1, F2, F3, F6, N1, N4, H5

### Móvil (390)
- No hay tablero móvil propio de esta pantalla (el móvil de admin es `AdminMovil.dc.html` = M1m, que enlaza aquí desde «Secciones»).

## Secciones

### 1. Cabecera y aviso
- **Contenido:** título «Comunidades»; subtítulo «Consulta de comunidades. Solo lectura.» Aviso con candado (Material `lock`, FA `fa-lock`): «La API no permite editar ni eliminar comunidades.»
- **Estilo:** `.row.sp.wrapf` (flex, `justify-content:space-between`, `flex-wrap:wrap`, `gap:12px`); a la izquierda `div.col` con `gap:2px`: `h1.t-title` (36/40 px, 600, `var(--h)`) y `p.muted` (`var(--muted)`). Aviso `.alert.al-info` (`var(--info-tint)` / `var(--info-fg)`).

### 2. Tabla de comunidades
- **Contenido:** cabeceras «Comunidad», «Acceso», «Jugadores», «Reglas» y una quinta vacía. Cada fila: nombre en negrita, etiqueta «Abierta» o «Cerrada», número de jugadores, nombre del conjunto de reglas y botón «Ver». Datos de ejemplo (no son requisitos): Amigos del paddock · Cerrada · 12 · Clásica 2026; Oficina F1 · Cerrada · 31 · Clásica 2026; Liga Pública · Abierta · 204 · Clásica 2026; Solo podio · Cerrada · 9 · Solo podio.
- **Datos:** `GET /v2/communities` → `Community[]`: Comunidad = `name`; Acceso = `open`; Jugadores = `membersAmount`; Reglas = `defaultRuleSet` (⚠️ a confirmar en API si trae `displayname` o solo id; las reglas son por temporada, 8.7).
- **Lógica:** `open === true` → «Abierta» con `.tag.tg-ok`; si no → «Cerrada» con `.tag.tg-brand`. Orden propuesto: jugadores descendente (⚠️ a confirmar; el mockup no ordena).
- **Estados:** sin reglas → «—» (⚠️ a confirmar).
- **Interacción:** «Ver» es enlace a H5 con el id de la comunidad.
- **Estilo:** `.card` > `.tw` > `table.tbl.tn`; nombre `b.hd`; jugadores `.r`; «Ver» `a.btn.btn-ghost.btn-sm`. `.tg-ok` (`var(--ok-tint)`/`var(--ok-fg)`), `.tg-brand` (`var(--tint)`/`var(--tint-fg)`).
