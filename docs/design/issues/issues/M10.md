## Objetivo
Consulta de las cuentas de usuario para el admin. Es solo lectura: la API no permite editar, activar, desactivar ni borrar usuarios de otros (decisión 17.4, requisito 12.13). Muestra usuario, correo, fecha de alta, número de comunidades y estado de verificación, con buscador.

## Ruta y acceso
- Ruta propuesta: `/admin/usuarios` (búsqueda en `?q=`) (rutas tipadas y carga perezosa de T3, bajo el layout admin de N4).
- Requiere sesión: sí, con correo verificado (guards `auth` y `verified`, requisito 1.6).
- Rol: administrador (guard `admin`: `User.rank.admin === true`; si no, redirige a `/404`, requisito 12.1). No necesita comunidad activa.
- Entradas: enlace «Usuarios» del grupo «Personas» de `AdminSide`; fila «Usuarios» de M1m.
- Salidas: ninguna en el mockup. 12.13 pide también detalle (`GET /v2/user/{user}`): se propone enlazar el nombre a U2 (perfil de otro usuario) (⚠️ a confirmar).

## Secciones

### 1. Cabecera y aviso
- **Contenido:** título «Usuarios»; subtítulo «Consulta de cuentas. Solo lectura.» Aviso con icono de candado (Material `lock`, FA `fa-lock`): «La API no permite editar ni eliminar usuarios, así que esta pantalla es de consulta.»
- **Estilo:** `.row.sp.wrapf` (flex, `justify-content:space-between`, `flex-wrap:wrap`, `gap:12px`); a la izquierda `div.col` con `gap:2px`: `h1.t-title` (36/40 px, 600, `var(--h)`) y `p.muted` (`var(--muted)`). Aviso `.alert.al-info` (flex, `gap:12px`, `padding:12px 16px`, radio 4px, 14/20 px, fondo `var(--info-tint)`, texto `var(--info-fg)`).

### 2. Buscador
- **Contenido:** input con icono de lupa (Material `search`, FA `fa-magnifying-glass`) y placeholder «Buscar por nombre o correo».
- **Datos:** `GET /v2/user` → `User[]` (⚠️ a confirmar en API si admite búsqueda/paginación en servidor).
- **Lógica:** filtro sin distinguir mayúsculas ni tildes sobre `username` y `email`, con `debounce` de 300 ms (VueUse); el término se refleja en `?q=`.
- **Estilo:** `.card-b.row.g8.wrapf`; `div.iw.fx` (`min-width:220px`) con icono absoluto a `left:10px` en `var(--muted)` e `.inp` con `padding-left:36px`.

### 3. Tabla de usuarios
- **Contenido:** cabeceras «Usuario», «Correo», «Alta», «Comunidades» (derecha), «Estado». Cada fila: avatar de 24px con iniciales + nombre en negrita; correo; fecha de alta (ejemplo «mar 2024»); número de comunidades; etiqueta «Verificado». Pie de tarjeta: «Mostrando {n} de {total}» (ejemplo «Mostrando 12 de 312»). Datos de ejemplo: los 12 usuarios de `seed.js` con correos `{id}@ejemplo.com` (no son requisitos).
- **Datos:** Usuario = `User.username` (⚠️ a confirmar si hay nombre visible distinto); avatar = `/v2/user/{user}/image` si `hasProfileImage`, si no iniciales; Correo = `User.email`; Alta = `User.created`; Estado = `User.verified`; Comunidades: `User` no trae el número (⚠️ a confirmar en API; `GET /v2/user/{user}/communities` exigiría una petición por fila). Nunca leer ni mostrar `hashedPassword` (24.8).
- **Lógica:** Alta con mes abreviado en minúscula sin punto y año: `Intl.DateTimeFormat('es-ES',{month:'short',year:'numeric'})` → «mar 2024» (quitar el punto si `Intl` lo añade). Iniciales: primera letra de las dos primeras palabras en mayúscula (ejemplo «Álex Ruiz» → «ÁR»). El usuario actual lleva avatar `.you`. «Mostrando {n} de {total}» con `n` = filas visibles tras filtrar y `total` = total de usuarios.
- **Estados:** `verified` → `.tag.tg-ok` «Verificado»; no verificado → `.tag.tg-warn` «Sin verificar» (⚠️ texto y color a confirmar; el mockup solo dibuja «Verificado»). Avatar del usuario actual `.av.you` (fondo `var(--primary)`, texto blanco); resto `.av` (fondo `var(--tint)`, texto `var(--tint-fg)`).
- **Interacción:** sin acciones por fila. Paginación: el pie solo muestra el recuento; si la lista es larga, paginar de 50 en 50 con la paginación de F3 (⚠️ a confirmar).
- **Estilo:** `.tw` > `table.tbl.tn`; celda usuario `span.row.g8` con `span.av.s24` (24px, 10px) y `b.hd`. Pie `.card-f` con `justify-content:flex-start` y `span.t-sm.muted`.

## Accesibilidad
- El input de búsqueda lleva `aria-label="Buscar"` (del mockup); mejor «Buscar usuarios».
- El recuento «Mostrando n de total» en una región `aria-live="polite"` para anunciar el resultado del filtro.
- Avatares con iniciales `aria-hidden="true"` (el nombre ya está en texto).
- La etiqueta de estado es texto, no solo color.
