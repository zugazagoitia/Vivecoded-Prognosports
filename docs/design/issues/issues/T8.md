## Objetivo
Cero errores de lint desde el primer día y formato automático, para que las PR solo discutan contenido.

## Alcance
- **oxlint** como primer paso rápido (`pnpm lint:ox`).
- **ESLint flat config** (`eslint.config.ts`) con `eslint-plugin-vue` (`flat/recommended`), `typescript-eslint` (con type-checking) y `eslint-plugin-oxlint` para no duplicar reglas.
- Reglas propias:
  - prohibir `v-html` (§23.3) salvo con comentario de excepción y HTML saneado;
  - prohibir `fetch` directo fuera de `src/api/` (`no-restricted-globals` / `no-restricted-imports`);
  - `vue/no-bare-strings-in-template` para forzar i18n (T5), si no da demasiados falsos positivos;
  - `vuejs-accessibility` (botones de icono con `aria-label`, etiquetas en campos).
- **Formato**: Prettier (o `oxfmt` si ya es estable) + `.editorconfig`. Incluye `prettier-plugin-tailwindcss` para ordenar clases.
- **Pre-commit** con Lefthook: lint y formato solo de los archivos preparados; `typecheck` en `pre-push`.
- Scripts: `lint`, `lint:fix`, `format`, `format:check`.

## Criterios de aceptación
- [ ] `pnpm lint` y `pnpm format:check` pasan en limpio en `main`.
- [ ] Un commit con un error de lint se bloquea en local.
- [ ] Un `v-html` o un `fetch` fuera de `src/api/` da error.
